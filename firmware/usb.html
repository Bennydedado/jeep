Install the Jeep T3, step by step

Same program as the regular installer, but you can see every step, it can't get stuck forever, and it has two ways around a fussy USB connection. Chrome or Edge on a computer; close the Arduino IDE first. Your saved Wi-Fi and sheet link stay on the T3 (nothing is erased).

  1. Download the T3 program
  2. Connect to the T3
  3. Start the helper
  4. Write the program
  5. Restart the T3
Details (send Claude a screenshot of this if something goes wrong) 

  

  
No COM port to pick? The computer needs the T3's USB driver: install WCH CH343SER (wch-ic.com), then plug the T3 in again.
