Install the Jeep T3

You only do this once. After that the T3 updates itself over Wi-Fi whenever the Jeep is stopped, or over Bluetooth from Heep (Live > Wi-Fi & update).

  1. Use Chrome or Edge on the PC.
  2. Plug the T3 into the PC with its USB cable.
  3. Close the Arduino IDE (it holds the port). Click Install and pick the T3's COM port: the one that appears when you plug it in.
  4. If it sits on "Connecting" or fails to start, hold the T3's BOOT (IO0) button while you click Install.
  5. When it says Installation complete, unplug it for a few seconds and plug it back in: the screen says Jeep T3.

Step-by-step installer

If no COM port shows up, the PC needs the T3's USB driver: search for the WCH CH343SER driver, install it, and plug the T3 in again. If a try gets stuck, unplug the T3, reload this page and try again.
